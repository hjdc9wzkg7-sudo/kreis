# KREIS

**Finde diese Woche deinen kleinen Kreis — nicht den nächsten endlosen Feed.**

Social-App für 4–8 Personen mit wiederkehrenden Ritualen: kochen, Fotowalks, leichte Bewegung. Content ist Einladung und Erinnerung, nicht das Endprodukt.

## Struktur

```
apps/ios/     Native iOS-App (Expo / React Native)  ← Produkt
src/          Früher Web-Prototyp (Next.js)
```

Die iOS-App ist die führende Umsetzung des Konzepts.

## iOS-App starten

```bash
cd apps/ios
npm install
npm start
```

Auf dem iPhone: Expo Go öffnen und den QR-Code scannen.

Details: [apps/ios/README.md](apps/ios/README.md)

## Konzept

- Intention statt Hochglanzprofil
- Kreis-Saisons (2–4 Wochen)
- Private Momente statt Performance
- Endliche, erklärbare Entdeckung (max. 3/Tag)
- Sicherheit vor Wachstum: 18+, Treffpunkt erst nach RSVP, keine offenen Fremd-DMs
